Votre guide

Première connexion

  1. Ouvrez la création d’une clé GitHub ↗ dans votre compte bestcar146-afk.
  2. Nom : BEST CAR STAR — Livraisons. Choisissez une date d’expiration adaptée.
  3. Dans Repository access, choisissez Only select repositories, puis bestcar146-afk.github.io.
  4. Dans les autorisations du dépôt, accordez Contents: Read and write. Metadata reste en lecture.
  5. Générez la clé, conservez-la dans votre gestionnaire de mots de passe, puis collez-la dans Connecter GitHub. Ne la partagez pas dans une conversation.

Ajouter un véhicule

  1. Cliquez Ajouter un véhicule, puis renseignez le nom et la référence du châssis.
  2. Ajoutez la photo d’achat, la photo avant chargement, la photo installé dans le conteneur et la photo à Madagascar. Pour une photo HEIC, exportez-la d’abord en JPEG.
  3. Ajoutez un commentaire client si vous en avez un. Sinon, laissez ce champ vide.
  4. Enregistrer le brouillon conserve votre travail sur cet appareil. Téléchargez une sauvegarde pour le transférer sur un autre appareil.
  5. Prévisualiser montre toute la page telle que vos clients la verront.
  6. Publier les modifications envoie les parcours au site. Attendez le déploiement GitHub Pages, puis ouvrez Voir la page publique.

Modifier et organiser

Sélectionnez un véhicule à gauche pour le modifier. Les flèches changent l’ordre. Retirer enlève le parcours de la prochaine publication. Ces changements ne deviennent publics qu’après publication.

La page de gestion est accessible par son URL, mais seuls les utilisateurs disposant d’un accès GitHub en écriture peuvent publier. Aucun mot de passe ni clé n’est enregistré dans le site.
